# 模型下载说明

本仓库**不包含模型文件**（主模型 21.2 GB，太大），请自行下载后放到**本目录**下。

下载完成后，本目录应该长这样：

```
llama.cpp\models\
├── Qwen3.6-35B-A3B-uncensored-heretic-Q4_K_M.gguf  ← 主模型（必需，当前默认）
├── mmproj-BF16.gguf                                 ← 视觉投影（可选，不下载就退化为纯文本）
└── 下载模型.md                                       ← 本说明
```

> **为什么不用带 MTP 的版本**：本机（GTX 1060 3GB）实测，带 MTP 的
> `Qwen3.6-35B-A3B-UD-Q4_K_XL.gguf` 即使不开投机也慢约 14%（21.0 vs 23.7 t/s），
> 而**开启** `--spec-type draft-mtp` 更慢（掉到 10.5 t/s）。所以默认选无 MTP 版。
> 若你有强显卡、想保留 MTP 以便将来到大卡上开投机，可用

## 二、下载方式

**浏览器**：直接点上面的链接即可。

**命令行**（支持断点续传，下载 20 GB 时强烈建议）：

```bat
curl -L -C - -o "Qwen3.6-35B-A3B-uncensored-heretic-Q4_K_M.gguf" ^
  "https://hf-mirror.com/llmfan46/Qwen3.6-35B-A3B-uncensored-heretic-GGUF/resolve/main/Qwen3.6-35B-A3B-uncensored-heretic-Q4_K_M.gguf?download=true"
```

**huggingface-cli**（需要先 `pip install huggingface_hub`）：

```bat
set HF_ENDPOINT=https://hf-mirror.com
huggingface-cli download llmfan46/Qwen3.6-35B-A3B-uncensored-heretic-GGUF ^
  Qwen3.6-35B-A3B-uncensored-heretic-Q4_K_M.gguf --local-dir .
```

## 三、下载完检查一下

大小对不对是最快的判断方式：

| 文件 | 精确字节数 |
|---|---|
| Qwen3.6-35B-A3B-uncensored-heretic-Q4_K_M.gguf | 21,233,608,512 |
| mmproj-BF16.gguf | 902,822,528 |

（IQ3_S 等量化版的确切字节数随量化来源略有差异，以 `环境检查.bat` 报出的大小为准。）

也可以直接跑一次 `环境检查.bat`，它会报出模型的实际大小并和预期值（约 19.8 GB）比对。

## 四、换成别的模型的方法

1. 把新的 `.gguf` 下载到本目录；
2. 用记事本打开项目根目录的 `启动大模型.bat`，找到这一行：

   ```bat
   set "MODEL=%ROOT%llama.cpp\models\Qwen3.6-35B-A3B-uncensored-heretic-Q4_K_M.gguf"
   ```

   把文件名改成你的模型，保存。

3. **保存时请选 `ANSI` 编码**。这个脚本是 GBK + CRLF 的，用 UTF-8 保存会导致
   中文乱码、脚本崩溃。更稳妥的做法是改 `_维护脚本\gen_toggle.py` 后重新生成。

> 换模型后，**GPU 卸载的两个参数要同步**：`GPU_NLAYER` = 新模型层数，
> `GPU_LAYER_MIB` = 新模型「非专家权重」总量 ÷ 层数。后者可用
> `_维护脚本\gguf_inspect.py` 与显存实测确认。档位表里的速度/内存数值也会变，
> 建议重新用 `环境检查.bat` 确认内存是否够用。
