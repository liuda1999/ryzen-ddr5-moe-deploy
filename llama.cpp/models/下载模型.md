# 模型下载说明

本仓库**不包含模型文件**（主模型 21.3 GB，太大），请自行下载后放到**本目录**下。

下载完成后，本目录应该长这样：

```
llama.cpp\models\
├── Qwen3.6-35B-A3B-UD-Q4_K_XL.gguf     ← 主模型（必需）
├── mmproj-BF16.gguf                     ← 视觉投影（可选，不下载就退化为纯文本）
└── 下载模型.md                           ← 本说明
```

---

## 二、下载方式

**浏览器**：直接点上面的链接即可。

**命令行**（支持断点续传，下载 21 GB 时强烈建议）：

```bat
curl -L -C - -o "Qwen3.6-35B-A3B-UD-Q4_K_XL.gguf" ^
  "https://hf-mirror.com/unsloth/Qwen3.6-35B-A3B-MTP-GGUF/resolve/main/Qwen3.6-35B-A3B-UD-Q4_K_XL.gguf?download=true"
```

**huggingface-cli**（需要先 `pip install huggingface_hub`）：

```bat
set HF_ENDPOINT=https://hf-mirror.com
huggingface-cli download unsloth/Qwen3.6-35B-A3B-MTP-GGUF ^
  Qwen3.6-35B-A3B-UD-Q4_K_XL.gguf --local-dir .
```

## 四、换成 IQ3_S（小模型）的方法

1. 把 `Qwen3.6-35B-A3B-UD-IQ3_S.gguf` 下载到本目录；
2. 用记事本打开项目根目录的 `启动大模型.bat`，找到这一行：

   ```bat
   set "MODEL=%ROOT%llama.cpp\models\Qwen3.6-35B-A3B-UD-Q4_K_XL.gguf"
   ```

   把文件名改成 `Qwen3.6-35B-A3B-UD-IQ3_S.gguf`，保存。

3. **保存时请选 `ANSI` 编码**。这个脚本是 GBK + CRLF 的，用 UTF-8 保存会导致
   中文乱码、脚本崩溃。更稳妥的做法是改 `_维护脚本\gen_toggle.py` 后重新生成。

> 换成 IQ3_S 后，档位表里的速度和内存数值都会变（模型更小 → 更快、更省），
> 建议重新用 `环境检查.bat` 确认内存是否够用。
