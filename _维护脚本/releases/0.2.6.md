## 0.2.6 — 脚本中英双语 · 显存预算重写（实测标定）

> **项目定位**
>
> - **核心目的**：让本地**消费级显卡**（NVIDIA 独显，**主目标 8 GB 显存**，最低验证 3 GB）
>   跑动 **MoE 架构的 30B~35B 大模型**。
> - **优先级**：**实用性与 Token 生成速度优先**。
> - **设计目标**：生成速度**尽可能达到 25 token/s**；标定卡 GTX 1060 3GB 在 16K~32K 档
>   实测 **22~23 t/s**（稳态 `tg_3s` 22.8~23.5）。

### 相比 0.2.5 的变化

| | 0.2.5 | **0.2.6** |
|---|---|---|
| 脚本输出语言 | 纯中文 | **中英双语**（`正常/OK`、`[失败/FAIL]`、菜单与提示一律「中文 / English」） |
| 显存预算 | `(总显存 - 448) ÷ 64 MiB` 粗算 | **逐项实测标定**：总量 − 其它程序占用 − 计算/上下文 − 视觉塔 − KV − 安全垫 → 层数，并在启动信息里完整打印 |
| KV 精度 | 仅 ≥64K 才量化 | **按预算自动决定**：f16 装不下就换 q8_0（32K 省 ~320 MiB，代价 ~0.7% 速度） |
| 视觉塔 | 总是加载 | 新增 `MMPROJ_SW=off`（不载 mmproj，省 ~320 MiB 显存 + ~800 MiB 共享内存，代价是不能处理图片） |
| 显存告警 | 无 | 启动时读取**其它程序占用的显存**，超过 600 MiB 直接提示「建议先关掉浏览器/视频/游戏」 |
| 回归防护 | 无 | 新增 `_维护脚本\check_bat.py`：GBK 编码 / 括号平衡 / **块内变量括号展开**静态扫描 |

### 显存预算：为什么重写

先在 GTX 1060 3GB 上做了「层数 × 显存 × 速度」扫掠（32K / `--cpu-moe` / 24 线程）：

| -ngl | 专用显存 | 共享（host-mapped） | 生成 |
|---|---|---|---|
| 0 | 1535 MB | 112 MB | 13.75 t/s |
| 16 | 2397 | 302 | 17.18 |
| 24 | 2659 | 366 | 17.80 |
| 32 | 2612 | 750 | 19.50 |
| 40 | 2619 | 1198 | 20.50 |

两个结论直接改变了实现：

1. **专用显存会被驱动封顶**（约 2620 MB = 总量 − 其它程序 − 驱动保留），超出的权重落到
   host-mapped 共享内存，每 token 走 PCIe。所以预算必须算准 —— 算多了就有一部分权重长期走 PCIe。
2. 那约 1.2 GB「进内存」的权重**主要是视觉塔（mmproj）**，而且**不拖慢文本生成**
   （带 mmproj 20.46 / 不带 20.44 t/s，实测相同）。真正能省的是 **KV 精度**：
   32K 的 f16 KV 约 655 MiB，换 q8_0 只要 327 MiB，速度损失约 0.7%。

于是预算改为逐项列明（启动信息里会打印），并把「能多装 2 层以上就换 q8_0」作为默认策略。
本机 32K 档实测：**40 层 + q8_0 KV + 128 MiB 安全垫**，生成稳态 **22.8~23.5 t/s**。

> **关于「锁定显存」**：Windows 没有给应用「预留/锁定显存」的公开接口，
> 能做的是**把预算算准 + 留出安全垫 + 把占用大户告诉你**。本版三项都做了：
> 预算逐项打印、安全垫可配（`GPU_SAFETY_MIB`，默认 128，调大更保险但会少装几层）、
> 其它程序占用超过 600 MiB 时启动即告警。

### 脚本双语

`启动大模型.bat` / `环境检查.bat` / `开放局域网端口.bat` 的**全部用户可见输出**
（332 行）改为「中文 / English」双语，例如：

```
[6/11] 端口/Port 35035 状态 / status
        正常/OK    端口空闲 / port free，可以启动 / ready to start
  GPU 策略/STRATEGY   非专家权重上显存（40 层），专家留内存，单并发槽，KV q8_0
  显存预算/BUDGET   显存 3071 MiB - 其它程序 207 - 计算/上下文 480 - 视觉塔 320
                     - KV（q8_0）327 - 安全垫 128 → 可给权重 1609 MiB（÷40 = 40 层）
```

注释（`REM`）仍为中文，便于维护者阅读。

### 实测（32K 档验收，GTX 1060 3GB）

| 项目 | 结果 |
|---|---|
| 环境与安全检查 | 10/10 通过（双语输出，无乱码） |
| 显存预算 | 40 层 + q8_0 KV + 128 MiB 安全垫（启动信息逐项打印） |
| 生成速度 | 三轮 22.49 / 22.95 / 23.15 t/s；日志稳态 `tg_3s` 22.76~23.47 |
| llama 显存 | 专用 2524 MB（旧版 2619）+ 共享 1008 MB（旧版 1198）→ **自身占用少约 285 MB** |
| 关闭 | 端口释放、进程归零、内存回收 |

### 快速开始

1. 下载本页附件 **`ryzen-ddr5-moe-deploy-0.2.6-no-model.zip`**（约 10 MB），解压到任意目录
2. 双击 **`启动大模型.bat`** —— 首次会问你要哪个量化并自动下载（`2`=Q4_K_XL 推荐），
   下完接着选档位（回车=16K 实用档）、选用不用深度思考（回车=关闭）

> 网速慢或目标机不便联网时，也可以连模型一起拷过去；脚本检测到已有模型会跳过下载。
