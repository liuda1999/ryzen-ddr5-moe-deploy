## 0.2.7 — 非商业授权 · 文件名中英双语 · 定位纠偏 · 修掉一批显示与开关缺陷

> **项目定位**
>
> - **核心目的**：让本地**消费级显卡**（NVIDIA 独显，**主目标 8 GB 显存**，最低验证 3 GB）
>   跑动 **MoE 架构的 30B\~35B 大模型**。
> - **关键做法**：**显存与内存「混合用」** —— 每 token 必读的非专家权重放显存，
>   占大头的专家权重留内存；没有独显或显存不够时，纯 CPU 兜底照样能跑。
> - **优先级**：**实用性与 Token 生成速度优先**。
> - **设计目标**：生成速度**尽可能达到 25 token/s**；标定卡 GTX 1060 3GB
>   在 16K\~32K 档实测 **22\~23 t/s**（稳态 `tg_3s` 22.8\~23.5）。

### 三、项目定位纠偏：不是「免显卡」，是「显存与内存混合承担」

此前文档写成「零依赖 / 免显卡」，与真实意图不符。正确表述是：

> 消费级显卡的显存本来就少（8 GB 乃至 3 GB），装不下 30B\~35B 全部权重；
> 而 MoE 每个 token 只激活少量专家（本模型 256 选 8），于是**让显存与内存分头承担** ——
> 每 token 必读的非专家权重放显存让 GPU 跑，占大头的专家权重留内存、只搬当前激活的那几个。
> 两边协同比纯 CPU 明显更快；**没有独显、或显存不够时，纯 CPU 兜底照样能跑**。

README 顶部、`使用说明_UserGuide.md`、`部署说明_DeployNotes.txt` 与仓库简介均已按此重写。

### 四、修掉的缺陷

1. **「二合一开关」失效（影响最大）** —— 服务在运行时再次双击脚本，会打印
   `命令语法不正确。` 后**整个批处理中止**，菜单根本来不及显示。
   根因不在开关本身：上一版双语化时英文文案写成了
   `… send header: Authorization: Bearer <key above>`，那个 `<` `>` 被 cmd 当成
   **重定向符**，导致整条 `if defined API_KEY ( … )` 解析失败，而该语句在 `:SHOW_ADDR` 里、
   被「运行中菜单」和 `status` 调用 —— 于是「再双击一次」看起来完全没反应。
   **修法**：转义为 `^<key above^>`；并把开关改成**严格二合一**
   （无参数运行：没在跑就启动，**正在跑就直接关闭、不弹菜单**；
   想看「重启 / 开网页 / 看日志」菜单用新增的 `menu` 参数）。

2. **启动收尾看不到访问密钥** —— 同一个根因。修复后 `访问密钥/APIKEY …` 恢复正常显示。

3. **`开放局域网端口.bat` 的 `chcp` 会吞掉标准输入** —— 与另两个脚本不一致，已补 `<nul`。

4. **Markdown 里成对的单波浪号会被 GitHub 渲染成删除线** —— README 有一段大部分文字
   在网页上被横杠划掉。原因是 GFM 里**一对单 `~`** 就会包成 `<del>`（不需写两个），
   而那段里 `30B~35B` 与 `13~16 t/s` 各有一个。已把全部文档正文里的 120 处 `~` 转义为 `\~`
   （代码块与行内代码不转），并用 GitHub 自己的渲染接口逐篇验证：**`<del>` 数为 0**。

### 五、回归防护：三个静态检查脚本

| 脚本 | 查什么 |
|---|---|
| `_维护脚本\check_bat.py` | 生成的 .bat：GBK 编码、括号平衡、**echo 正文里未转义的 `<` `>`**、**`chcp` 是否带 `<nul`**、块内变量括号展开 |
| `_维护脚本\check_docs.py` | Markdown 文档：正文里未转义的 `~`（按段落 / 表格单元格统计）、代码围栏成对、**换行与行尾是否被外部工具改写**、引用的文件名是否存在 |

> 另有一次本地 README 被某个 Markdown 工具「往返转换」（行尾变 `CR + 空格`、
> badge 外链外壳被剥掉），现在这类改写会被当场报出来。

### 七、快速开始

1. 解压到任意目录（建议英文路径），双击 **`启动大模型_StartModel.bat`**；
2. 首次运行会自动做 11 项环境与安全检查；**没有模型时会引导你下载**
   （输入 `1` = IQ3_S / `2` = Q4_K_XL，用系统自带 `curl` 断点续传）；
3. 按显存推荐选配置档位 → 选是否开启深度思考 → 等待约 30\~90 秒；
4. 显示「启动成功」后，浏览器打开提示的地址即可对话。
   **同一个脚本再运行一次就是关闭服务**（严格二合一）；
   想看管理菜单：`启动大模型_StartModel.bat menu`。
