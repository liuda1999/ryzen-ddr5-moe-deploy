## 首个发布版本

在 **Windows + 纯 CPU + 无显卡**的机器上，把 Qwen3.6-35B-A3B（MoE）跑成开箱即用的本地服务。

这一版把 llama.cpp 在纯 CPU 上跑到可用的**全部工程细节固化下来**：
编译哪些 CPU 指令集变体、线程给多少、上下文开多大、内存够不够、密钥怎么给、
局域网怎么开——都已调好并实测过。

---

### 硬件要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 **x64** |
| 内存 | **≥ 32 GB**（推荐 64 GB；默认档位需约 30 GB 可用） |
| 磁盘 | Q4_K_XL 约 **25 GB**；IQ3_S 约 **17 GB** |
| 显卡 | **不需要** |
| 运行时 | **什么都不用装**（VC++ 运行库已随包附带，PowerShell / curl 系统自带） |

---

### 快速开始

1. 下载本页附件 **`qwen3.6-35b-a3b-cpu-deploy-0.1.0-no-model.zip`**（约 10 MB），解压到任意目录
2. 按下方链接下载模型，放进 `llama.cpp\models\` 目录
3. 双击 **`启动大模型.bat`** —— 选档位（回车=实用档）、选用不用深度思考（回车=关闭），约 15~30 秒后启动成功

> 同一个脚本再运行一次就是**关闭服务**。想确认在不在：`启动大模型.bat status`。

### 本版内容

- **llama.cpp 编译产物**：官方 `ggml-org/llama.cpp`（0.6.0-dev）编译，
  含 **9 个 CPU 指令集变体**（运行时自动择优）+ VC++ 运行时 DLL，免安装
- **`启动大模型.bat`**：二合一开关，未运行则启动、已运行则关闭；
  内置 9 项环境与安全检查，按实际可用内存预检档位可行性；
  就绪判定基于 `/health` 轮询（避免「端口一监听就报成功」的假成功）；
  服务**无窗口静默运行**；首次启动自动生成 API 密钥并复制到剪贴板
- **`环境检查.bat`**：10 项环境与安全体检
- **`开放局域网端口.bat`** / **`重新编译.bat`**
- **中文文档**：使用说明、参数阶梯手册、部署说明、验收报告、分发包清单
- **实测档位数据**（12 个测试点）

### 实测性能（AMD Ryzen 9 9950X，16 物理核，61.6 GB 内存）

| 档位 | 上下文 | 线程 | 生成速度 | 约需内存 |
|---|---|---|---|---|
| 1 极速档 | 12K | 24 | 13.28 t/s | 28 GB |
| **2 实用档（默认）** | **16K** | **24** | **12.73 t/s** | **30 GB** |
| 3 长文档档 | 24K | 24 | 11.82 t/s | 34 GB |
| 4 超长档 | 32K | 24 | 9.95 t/s | 38 GB |
| 5 极限档 | 64K | 28 | 4.28 t/s | 55 GB |

三条规律：24 线程在所有档位都比 28 线程快；prefill（读提示）约 **70 token/秒**是硬件上限；
**首次对话等多久取决于客户端发了多长的提示**（注入了上万 token 的 system prompt / 工具定义时，
等几分钟属正常）。

> 换 CPU 平台**无需重新编译**，但档位速度表与线程数需按新 CPU 重定。
> 详见仓库内《参数阶梯手册.md》的「平台声明」。

### 安全提示

服务默认绑定 `0.0.0.0` 且启用了 API 密钥鉴权。要开放给局域网其它设备，
需以管理员身份运行一次 `开放局域网端口.bat` 放行防火墙端口。

放行后，**同网段任何拿到密钥的设备**都能占用你的 CPU 与内存做推理（默认档位单次约 30 GB）。
在咖啡厅、酒店等不可信 Wi-Fi 下，建议把 `启动大模型.bat` 里的
`set "HOST=0.0.0.0"` 改回 `set "HOST=127.0.0.1"` 后重启。
